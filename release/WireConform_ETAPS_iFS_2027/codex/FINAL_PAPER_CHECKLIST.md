# Paper submission checklist for Codex and author

## Research evidence
- [ ] OpenAPI 3.1.1 normative oracle checked against official table and a separate independent implementation
- [ ] All 117 cases checked against external OAS schema validator, or invalid cases accounted for honestly
- [ ] Generated SDKs version-locked; source-generation logs available
- [ ] Generated-code invocations genuine, header cases addressed
- [ ] Frozen 14-case pilot actually executed for each generator; exclusion counts reported
- [ ] Full 117-case matrix executed where support exists; per-tool denominators disclosed
- [ ] No synthetic fixture presented as SDK outcome
- [ ] Mismatch replay with original standalone spec (bundle effect excluded)
- [ ] Evidence for any new issue cross-checked against upstream and literature
- [ ] Repro scripts, hashes, environment and raw observations included

## iFS 2027 requirements
- [ ] Submission category: short empirical evaluation paper
- [ ] Oct 15 2026 AoE deadline met; online portal entry manually checked
- [ ] Springer `llncs.cls`, PDF legible and visually inspected
- [ ] 8 pages MAIN, <= 1 page references; data statement just before references
- [ ] Abstract / results / conclusions correspond exactly to measured observations
- [ ] No unsupported novelty or prevalence claims
- [ ] Author block and submission anonymization rule resolved
- [ ] Paper not already published or under simultaneous conference submission
- [ ] All citations genuinely support claims and are accurately formatted
- [ ] Presentation-on-acceptance requirement considered
- [ ] Final PDF + TeX + all evidence files archived
- [ ] Final research audit includes explicit GO / NO-GO

Do not self-attest any item as done without an auditable output.
